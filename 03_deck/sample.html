2-3이항분포 → 정규분포

n ↑ → 이항분포 B(n, p) ≈ 정규분포 N(np, npq)

  • 막대 = B(n, 1/2) 확률 · 가로축 표준화
  • n = 1 → 64 · 막대 윤곽 → 종 모양
  • n 충분히 큼 → 정규분포로 근사 계산
$B(n,p)\;\approx\;N(np,\,npq)$

3-1정규분포

N(m, σ²) = 평균 m → 위치 · 표준편차 σ → 퍼짐

  • m 변화 → 곡선 좌우 이동
  • σ ↑ → 낮고 넓게 · σ ↓ → 높고 좁게
  • 곡선 아래 넓이 = 1 · x = m 대칭
  • 점선 = 표준정규분포 N(0, 1)
$f(x)=\dfrac{1}{\sqrt{2\pi}\,\sigma}\,e^{-\frac{(x-m)^2}{2\sigma^2}}$

핵심키 · 측정 오차 · 제품 수명 → 정규분포 근사R01 p.99–100

$Z=\dfrac{X-m}{\sigma}\;\sim\;N(0,\,1)$

4-2모평균의 신뢰구간

신뢰도 95% = 같은 방법 100번 → 약 95개 구간이 m 포함

$\bar{x}-1.96\dfrac{\sigma}{\sqrt n}\le m\le\bar{x}+1.96\dfrac{\sigma}{\sqrt n}$

예시: σ = 20 g · n = 25 → x̄ ± 7.84 · 점선 m = 250

5-1seaborn 시각화

seaborn = 분포 시각화 한 줄

import numpy as np
import seaborn as sns

rng = np.random.default_rng(42)
x = rng.binomial(n=10, p=0.5, size=1000)
# 갈톤 보드 공 1,000개
z = rng.normal(loc=50, scale=15, size=1000)
# N(50, 15²) 1,000개

sns.histplot(x, discrete=True, stat="probability")
sns.histplot(z, kde=True, stat="density")
